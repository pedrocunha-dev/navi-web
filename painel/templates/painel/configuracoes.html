What is Groq?
Groq is a high-speed cloud inference platform that provides language models free of charge for moderate use. No credit card required to get started.

What is it used for here?
The key is required only when the "Scrape individual descriptions (AI)" option is enabled on the dashboard. With it, NAVI visits each listing individually, reads its full description, and uses AI to automatically extract the Built Area and Land Area — fields that typically do not appear on listing cards.

Model used: openai/gpt-oss-120b
An open-source language model with advanced reasoning capabilities, hosted on Groq's infrastructure. Particularly effective at structured information extraction from property description texts.

How to get the key:
Go to groq.com, create a free account → go to API Keys → click Create API Key. Copy the generated key and paste it in the field below.
