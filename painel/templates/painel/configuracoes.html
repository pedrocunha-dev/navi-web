O que é a Groq?
A Groq é uma plataforma de inferência em nuvem de altíssima velocidade, que disponibiliza modelos de linguagem gratuitamente para uso moderado. Não requer cartão de crédito para começar.

Para que serve aqui?
A chave é necessária apenas quando a opção "Raspar descrições individuais (IA)" está ativada no painel. Com ela, o NAVI visita cada anúncio individualmente, lê a descrição e usa IA para identificar automaticamente a Área Construída e a Área do Terreno — campos que normalmente não aparecem nos cards de listagem.

Modelo utilizado: openai/gpt-oss-120b
Modelo de linguagem open-source da OpenAI com capacidade de raciocínio avançado (reasoning), hospedado na infraestrutura da Groq. É especialmente eficaz na extração estruturada de informações de textos em português.

Como obter a chave:
Acesse groq.com, crie uma conta gratuita → vá em API Keys → clique em Create API Key. Copie a chave gerada e cole no campo abaixo.

Deixe em branco para desabilitar a raspagem com IA.
